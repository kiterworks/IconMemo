## 关于赞助二维码的几点提醒

1. **建议用「赞赏码」而不是「收款码」**
   个人收款码被他人用于异常交易时可能牵连账户；赞赏码有金额上限、支持留言，风险更低。

2. **二维码公开后是永久的**
   一旦提交到公开仓库，历史记录里就会一直存在。换码需要改 README 并重新提交，
   旧码仍可被从历史中翻出。建议先确定长期使用的收款方式再放图。

3. **可以考虑用第三方平台隔离**
   如爱发电等平台的赞助页，配一张指向该页面的二维码 —— 个人账户信息不直接暴露。

4. **务必自测**
   放上去之前用自己的手机扫一次，确认金额、备注、收款方都正确。

## 在放图之前

README 里已经预留了引用位置：

```html
<img src="assets/sponsor-qr.png" alt="赞助二维码" width="220">
```

把图片作为 `sponsor-qr.png` 放进本目录即可，无需改 README。
如果暂时不想放，把 README「赞助」一节删掉，或保留文字说明即可。
